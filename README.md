1. サービス概要

このサービスは、親の語りかけをサポートすることで、子どもの言語発達と情緒の安定を支援する知育アプリです。
画像を使ったシンプルな課題を通じて、親子の「会話」を自然に生み出します。
特に、癇癪や言葉の未発達に悩む家庭に対し、「関わり方」を提供することで解決を目指します。

⸻

2. このアイデアはどこから生まれたか

2-1. きっかけとなった体験・感情

育児の中で、子どもがうまく言葉で気持ちを表現できず、癇癪を起こしてしまう場面に何度も直面しました。

* 子どもが泣いている理由が分からない
* どう声をかければいいのか分からない
* 忙しさや余裕のなさから、十分に向き合えない

その結果、
「ちゃんと関わってあげたいのにできていない」
という強いストレスと罪悪感を感じました。

⸻

2-2. なぜそれが「気になった」のか

自分自身が介護経験を通して、
「人に寄り添うことの大切さ」を強く感じていたためです。

また、

* 家族との時間を大切にしたいという価値観
* 子どもの将来に対する不安
* 自分の関わり方が影響してしまうのではないかという責任感

これらが重なり、「関わり方そのもの」を支援する必要性を感じました。

⸻

3. 課題の整理（表面的になっていないか）

3-1. 表に見えている困りごと

* 子どもが癇癪を起こす
* 言葉がうまく出ない
* 親がどう声かけすればいいか分からない

⸻

3-2. 本当に解決したい課題は何か

* なぜ癇癪が起きるのか？
    → 気持ちを言葉で表現できない
* なぜ表現できないのか？
    → 語彙・経験・対話が不足している
* なぜ対話が不足するのか？
    → 親が関わり方に自信がない / 余裕がない

⸻

🔸本当に解決したい課題：
親が安心して子どもと向き合い、言葉と感情のやり取りができる状態を作ること

⸻

4. 想定ユーザーについて

4-1. 想定しているユーザー

年齢設定：

* 年齢：1〜3歳の子どもを持つ親
* 理由：言語発達と癇癪が重なりやすい時期のため

生活・状況設定：

* 育児・家事・仕事で忙しい
* 子どもと向き合いたいが余裕がない
* 声かけに自信がない / 子どもの反応を引き出す質問が思いつかない

理由：
→ アプリが「声かけの型」を提供することで負担を軽減できる

環境設定：

* ワンオペ育児の可能性
* 時間が限られている

理由：
→ 短時間（5〜10分）で親子の関わりを作れる設計にする

⸻

4-2. 自分とユーザーの距離

→ 自分自身

理由：
実際に同じ悩みを経験しており、リアルな課題として捉えているため

⸻

4-3. 実際に使われる可能性について

* 最初に使う人：育児に悩みを感じている親
* 思い出す場面：寝る前・癇癪が増えてきた時
* 代替手段：YouTube・読み聞かせアプリ・放置

🔸それらとの違い
→ 親が関わることを前提にしている点

⸻

4-4. 導入・継続の流れ

* 夜の寝る前に「使ってみよう」となる
* 子どもの誕生日を登録
* その日の課題を提示
* 親が問いかけを行う

継続理由：

* 子どもとの関係が良くなる実感
* 癇癪の減少
* 習慣化（寝る前ルーティン）

⸻

5. 既存サービス・競合調査

5-1. 似たサービス

* サービス名：KIKASETE -きかせて-
* できること：
    * 読み聞かせ
    * AIによる問いかけ
    * 子どもの発話促進

⸻

5-2. それでも作りたい理由

* AI主導で親の関与が薄い
* 「どう関わるか」の具体的な支援がない
* 親の声の価値が活かされていない
（AIの音声：　単方向の情報の受け取りになりやすい
　親との対面での音声： 子の集中力が高い / 親子の絆や安心感、共感力を育む / 反応に応じたやり取りで言語獲得の効果が高い）

⸻

5-3. 差別化

🔸私のアプリの差別化ポイント：

「子どもではなく親の関わり方を支援する」ことに特化している点

⸻

6. このサービスで提供したい価値

6-1. ユーザーの変化

行動：

* 子どもに話しかける回数が増える

気持ち：

* 育児への不安が減る
* 子どもとの時間が楽しくなる

考え方：

* 正解より「対話」が大事と理解できる

⸻

6-2. 価値

このサービスは
育児に悩む親が、子どもとの会話に自信を持てるようになるサービス

⸻

7. このアプリで実現すること

MVPで作る機能

* ユーザー登録
* 子どもの誕生日登録
* 画像表示（間違い探し）
* 質問表示（1問）
* 「できた」ボタン

⸻

本リリースで作る機能

* 読み聞かせ機能
* 音声再生
* 選択肢による難易度別（easy/normal/hard）の問題提示
* 親向け声かけガイド
* リマインド機能（寝る前習慣）
* AIによる質問生成
* 成長記録

⸻

発達段階に応じた設計思想

本サービスは以下の考え方に基づく：

0〜2歳

* 親の声が主役　　　▶親の声の響きや肌の温もりが安心感に直結）
* 相槌・反応が重要　▶言語獲得の基礎となる『やり取り』の補完　

3〜5歳

* 語彙を広げる時期　　▶親が知らない多様な言葉や表現を読み聞かせアプリで補う
* アプリの補助を活用　▶親が物語の展開に合わせて、「次どうなるかな？」などの問いかけを入れて、想像力を育てる

6歳〜

* 自立読書への移行　

🔸MVPでは1〜3歳に絞り
🔸本リリースで拡張予定

⸻

* バックエンド：Ruby on Rails7.1.3 / Ruby3.2.2

* DB：PostgreSQL
* フロントエンド :Hotwire (Turbo, Stimulus) + ERB + Tailwind CSS
* デプロイ：Render
