
1. サービス概要

このサービスは、親の語りかけをサポートすることで、子どもの言語発達と情緒の安定を支援する知育アプリです。
画像を使ったシンプルな課題を通じて、親子の「会話」を自然に生み出します。
特に、癇癪や言葉の未発達に悩む家庭に対し、「関わり方」を提供することで解決を目指します。

⸻
2. このアイデアはどこから生まれたか

2-1. きっかけとなった体験・感情

育児の中で、子どもがうまく言葉で気持ちを表現できず、癇癪を起こしてしまう場面に何度も直面しました。

* 子どもが泣いている理由が分からない
* どう声をかければいいのか分からない
* 忙しさや余裕のなさから、十分に向き合えない

その結果、
「ちゃんと関わってあげたいのにできていない」
という強いストレスと罪悪感を感じました。

⸻
2-2. なぜそれが「気になった」のか

自分自身が介護経験を通して、
「人に寄り添うことの大切さ」を強く感じていたためです。

また、

* 家族との時間を大切にしたいという価値観
* 子どもの将来に対する不安
* 自分の関わり方が影響してしまうのではないかという責任感

これらが重なり、「関わり方そのもの」を支援する必要性を感じました。

⸻
3. 課題の整理（表面的になっていないか）

3-1. 表に見えている困りごと

* 子どもが癇癪を起こす
* 言葉がうまく出ない
* 親がどう声かけすればいいか分からない

⸻

3-2. 本当に解決したい課題は何か

* なぜ癇癪が起きるのか？
    → 気持ちを言葉で表現できない
* なぜ表現できないのか？
    → 語彙・経験・対話が不足している
* なぜ対話が不足するのか？
    → 親が関わり方に自信がない / 余裕がない

⸻

🔸本当に解決したい課題：
親が安心して子どもと向き合い、言葉と感情のやり取りができる状態を作ること
